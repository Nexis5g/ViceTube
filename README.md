# ViceTube — инструкция по сайту

## 1. О сайте

**ViceTube** — учебный сайт для просмотра и размещения видеоматериалов, выполненный в стиле современного видеохостинга.

Основные страницы:

- `index.html` — главная страница, поиск, категории и рекомендации.
- `watch.html` — просмотр выбранного видео и управление плеером.
- `history.html` — история просмотров.
- `login.html` — авторизация и создание локального профиля.
- `account.html` — личный кабинет и настройки профиля.
- `upload.html` — добавление нового видео.
- `videos.json` — каталог видео.
- `site-profile.js` — общая логика профиля и оформления.

---

ViceTube/

## 3. Запуск сайта

### Через локальный сервер Python

Откройте терминал в папке сайта и выполните:

```bash
python -m http.server 8000
```

Затем откройте в браузере:

```text
http://localhost:8000
```

### Через Visual Studio Code

1. Откройте папку ViceTube.
2. Установите расширение **Live Server**.
3. Откройте `index.html`.
4. Нажмите **Open with Live Server**.

> Запуск через локальный сервер рекомендуется, потому что сайт загружает данные из `videos.json`.

## 4. Главная страница — index.html

На главной странице находятся:

- логотип ViceTube;
- строка поиска;
- кнопка профиля;
- категории видео;
- каталог видео;
- рекомендации.

### Поиск

Введите название или ключевое слово в строку поиска. Сайт отфильтрует подходящие видео.

### Категории

Используются категории:

- Развлекательное;
- Познавательное;
- Обзоры;
- Игры.

Выбранная категория выделяется основным цветом профиля, остальные остаются нейтральными.

### Профиль

Кнопка аватара позволяет перейти к истории просмотров и другим функциям профиля.

---

## 5. Страница просмотра — watch.html

На странице просмотра находятся:

- видеоплеер;
- воспроизведение и пауза;
- перемотка;
- ползунок прогресса;
- регулировка громкости;
- полноэкранный режим;
- информация о видео;
- лайки;
- комментарии.

После просмотра видео информация о просмотре сохраняется локально и используется на странице истории.

---

## 6. История — history.html

На этой странице отображаются просмотренные пользователем видео.

История хранится в браузере и привязана к локальному профилю.

---

## 7. Авторизация — login.html

В текущей версии авторизация работает локально в браузере.

В профиле могут храниться:

- имя пользователя;
- аватар;
- цвет оформления;
- история просмотров;
- настройки профиля.

Данные сохраняются в `localStorage`.

> Это не серверная регистрация. Данные профиля не передаются на сервер.

При очистке данных сайта браузера локальный профиль может быть удалён.

---

## 8. Личный кабинет — account.html

В личном кабинете можно настроить профиль:

- изменить имя пользователя;
- изменить аватар;
- изменить баннер;
- выбрать основной цвет оформления.

Если баннер не установлен, используется белый фон.

Стандартный гостевой аватар — `Guest.jpg`.

---

## 9. Загрузка видео — upload.html

На странице загрузки можно добавить информацию о новом видео:

- название;
- описание;
- ссылку на видео;
- превью;
- хэштеги.

Пример хэштегов:

```text
#игры #обзор #steam
```

Хэштеги сохраняются как отдельные элементы массива.

---

## 10. Как сохраняются новые видео

Браузер не может самостоятельно перезаписать исходный файл `videos.json` на компьютере пользователя.

Поэтому добавленное через форму видео сначала сохраняется в `localStorage`.

После добавления сайт может сформировать обновлённый `videos.json` для скачивания.

Чтобы сделать изменения постоянными:

1. Скачайте новый `videos.json`.
2. Замените старый `videos.json` в папке сайта.
3. Перезагрузите сайт.

---

## 11. Файл videos.json

`videos.json` содержит информацию о каталоге видео.

Пример структуры записи:

```json
{
  "id": 1,
  "title": "Название видео",
  "description": "Описание видео",
  "url": "video.mp4",
  "thumbnail": "preview.jpg",
  "hashtags": [
    "#игры",
    "#обзор"
  ]
}
```

При ручном редактировании необходимо соблюдать синтаксис JSON:

- использовать двойные кавычки;
- разделять элементы запятыми;
- не ставить лишнюю запятую после последнего элемента;
- сохранять правильную структуру скобок.

---

## 12. localStorage

Сайт использует локальное хранилище браузера для пользовательских данных.

В зависимости от версии могут использоваться ключи:

```text
account
uploadedVideos
videoViews
videoThumbnails
videoComments
likes
likedVideos
```

Основное назначение:

| Ключ | Назначение |
|---|---|
| `account` | данные профиля и настройки |
| `uploadedVideos` | видео, добавленные через сайт |
| `videoViews` | информация о просмотрах |
| `videoThumbnails` | сохранённые превью |
| `videoComments` | комментарии |
| `likes` | количество лайков |
| `likedVideos` | понравившиеся видео |

---

## 13. site-profile.js

`site-profile.js` отвечает за общие элементы профиля на страницах сайта.

Скрипт:

- получает данные профиля из `localStorage`;
- устанавливает аватар;
- устанавливает выбранный цвет оформления;
- добавляет логотип на страницы, где он отсутствует;
- добавляет кнопку профиля на необходимые страницы;
- обновляет профиль после изменения настроек.

Главная страница имеет собственную шапку. На странице загрузки видео шапка отсутствует.

---

## 14. Логотип и гостевой аватар

`logo.png` используется как логотип ViceTube и изображение сайта в интерфейсе.

`Guest.jpg` используется как стандартный аватар, если пользователь не установил собственный.

Чтобы заменить изображение, сохраните новый файл под тем же именем и положите его в корень сайта.

---

## 15. Оформление

Основной цвет интерфейса выбирается в профиле пользователя.

Он используется для основных элементов интерфейса, кнопок, ссылок и выделения выбранных элементов.

Элементы видеоплеера имеют собственное оформление и не обязаны полностью совпадать с цветом сайта.

---

## 16. Мобильная версия

Сайт адаптирован для небольших экранов.

На телефоне:

- шапка перестраивается;
- появляется меню категорий;
- поиск переносится ниже;
- карточки видео уменьшаются;
- элементы плеера становятся компактнее;
- страницы профиля и загрузки адаптируются под ширину экрана.

---

## 17. Ограничения текущей версии

Текущая версия ViceTube является клиентским сайтом без полноценной серверной базы данных.

Поэтому:

- профили хранятся локально;
- история хранится локально;
- лайки хранятся локально;
- комментарии хранятся локально;
- добавленные видео хранятся локально до обновления `videos.json`;
- данные одного браузера не синхронизируются автоматически с другими устройствами.

Для полноценного многопользовательского видеохостинга потребуется серверная часть, база данных и отдельное хранилище видео.

## 18. Быстрая инструкция пользователя

### Просмотр видео

1. Откройте главную страницу.
2. Найдите нужное видео.

2. Заполните форму.
3. Добавьте хэштеги.
4. Добавьте видео.

## 20. Заключение

ViceTube — клиентский видеохостинг с каталогом видео, поиском, категориями, рекомендациями, профилями пользователей, историей просмотров, лайками, комментариями и возможностью добавления видео.

Используемые технологии:

- **HTML** — структура страниц;

## 12. Каналы

В ViceTube добавлена система каналов. У каждого аккаунта есть собственный канал.

- `channel.html` — публичная страница канала.
- `channels.json` — каталог существующих каналов.
- Видео содержит `channelId` и `channelName`.
- При загрузке нового видео оно автоматически привязывается к каналу текущего аккаунта.
- На главной странице название канала под видео открывает его страницу.
- На странице просмотра название канала также ведёт на канал.
- На странице канала есть кнопка подписки; подписки сохраняются в `localStorage`.
- В личном кабинете можно изменить название канала и открыть свой канал.

Поскольку текущая версия ViceTube работает без серверной базы данных, каналы, подписки и профили хранятся локально в браузере. Для полноценной синхронизации между устройствами следующим этапом можно подключить Supabase.
